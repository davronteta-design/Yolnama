# 🗺️ Yolnama — Tour Flow

**Платформа-календарь для гидов и водителей**

Yolnama (Tour Flow) — это веб-приложение для планирования рабочего расписания туристических гидов. Оно позволяет вести учёт экскурсий, отмечать занятые и выходные дни, отслеживать доходы и управлять маршрутами — всё в одном интерфейсе без установки и регистрации.

---

## ✨ Возможности

- **Календарь** — отображение дней в режиме сетки (grid) или списка (list) с навигацией по месяцам
- **Типы дней** — 4 статуса: Экскурсия, Занят, Выходной, Личное
- **Бронирования** — добавление, редактирование, дублирование и удаление записей
- **Маршруты** — создание многодневных маршрутов одним действием (генерация дней по диапазону дат)
- **Статистика месяца** — количество экскурсий, занятых дней, туристов и суммарный доход
- **Мультивалютность** — поддержка UZS, USD, EUR и других валют
- **Поиск и фильтрация** — фильтр по статусу и поиск по имени тура / клиенту / городу
- **Мультиязычность** — интерфейс на русском 🇷🇺, английском 🇬🇧 и узбекском 🇺🇿
- **Данные сохраняются** в `localStorage` браузера — не теряются при перезагрузке страницы
- **Адаптивный дизайн** — работает на мобильных устройствах и десктопе

## 📖 Как пользоваться

### Добавить запись
1. Нажмите кнопку **«Добавить»** в шапке — откроется модальное окно.
2. Выберите тип дня: Экскурсия, Занят, Выходной или Личное.
3. Для экскурсии заполните город, заказчика, название тура, время, цену и количество туристов.
4. Нажмите **«Сохранить»**.

### Добавить маршрут
1. Нажмите **«Маршрут»** — откроется форма многодневного маршрута.
2. Укажите диапазон дат и нажмите **«Сгенерировать дни»**.
3. Для каждого дня введите город и программу.
4. Нажмите **«Сохранить»** — все дни добавятся в календарь автоматически.

### Редактировать / удалить запись
- Кликните на любой день в календаре → откроется карточка с деталями.
- Нажмите **«Редактировать»** для изменений или **«Удалить»** для удаления.

### Сменить язык
- В шапке справа выберите язык из выпадающего списка: **RU / EN / UZ**.

## 💾 Хранение данных

Все данные сохраняются в `localStorage` браузера под ключами:

| Ключ | Содержимое |
|---|---|
| `tour_flow_bookings` | Массив всех бронирований |
| `tour_flow_settings` | Настройки (язык, дефолтные значения форм) |

Данные не передаются на сервер и хранятся только локально на устройстве пользователя.
