# Yolnama

Персональный веб-органайзер для гидов и экскурсоводов. Позволяет бронировать рабочие дни, фиксировать экскурсии, отслеживать заказчиков, доходы и группы туристов.

---

## ✅ Реализованные функции

### Календарь
- 📅 Месячная сетка с навигацией (предыдущий/следующий месяц, кнопка «Сегодня»)
- 🗓️ Два вида отображения: **Сетка** (месяц) и **Список**
- 🎨 Цветные пометки на ячейках дней с типом записи
- 💰 Отображение суммы дохода прямо на ячейке дня
- 📆 Выделение сегодняшнего дня, выходных дней

### Типы записей
| Тип | Цвет | Описание |
|-----|------|----------|
| 🗺️ Экскурсия | Синий | Рабочая экскурсия с заказчиком |
| 🚫 Занят | Красный | День занят (без деталей) |
| 🏖️ Выходной | Зелёный | День отдыха |
| 🕐 Личное | Оранжевый | Личные дела |

### Форма бронирования
- **Заказчик** — название организации (Восток Тур, ООО Экскурс и т.д.)
- **Название тура** — наименование экскурсии/события
- **Город** — город проведения экскурсии
- **Время** — начало и конец экскурсии
- **Группа** — количество туристов
- **Оплата** — сумма + валюта (₽ RUB, $ USD, € EUR, сум UZS, ₸ KZT)
- **Заметки** — любые дополнительные данные
- Редактирование и удаление существующих записей

### Сайдбар
- 📊 Статистика за текущий месяц: количество экскурсий, занятых дней, выходных, туристов
- 💳 Суммарный доход за месяц
- 🗂️ Легенда типов записей
- 📋 Список ближайших предстоящих экскурсий

### UX/UI
- Адаптивный дизайн (desktop / tablet / mobile)
- Модальные окна с плавной анимацией
- Toast-уведомления об успехе/ошибках
- Кнопка обновления данных
- Плавающая кнопка FAB «Добавить запись»

## 🗄️ Модель данных (таблица `bookings`)

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | text | UUID записи |
| `date` | text | Дата `YYYY-MM-DD` |
| `status` | text | `excursion` / `busy` / `holiday` / `personal` |
| `client_name` | text | Название заказчика |
| `tour_name` | text | Название экскурсии/тура |
| `city` | text | Город проведения |
| `price` | number | Стоимость |
| `currency` | text | Валюта (RUB, USD, EUR, UZS, KZT) |
| `group_size` | number | Количество туристов |
| `start_time` | text | Время начала |
| `end_time` | text | Время окончания |
| `notes` | rich_text | Заметки |
| `color` | text | HEX цвет статуса |
